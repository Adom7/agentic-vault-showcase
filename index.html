01 — Vue d'ensemble

Le vault, source de vérité unique

Chaque session d'IA commence en lisant la même source, et termine en la mettant à jour. Pas de RAG externe, pas de base vectorielle — juste du Markdown versionné dans Git, structuré pour être lu par les humains et par les modèles.

04 — Sessions

Cycle de vie & compaction du contexte

Une session suit un protocole strict : pull → lecture mémoire → travail en micro-avancées commitées → compaction proactive → push final. Le contexte d'un modèle est une ressource limitée : on le gère, on ne l'attend pas. 

sequenceDiagram
    participant U as Utilisateur
    participant IA as Agent IA
    participant V as Vault Git
    participant R as Remote GitHub

    U->>IA: Lance la session
    IA->>V: git pull
    IA->>V: lit MEMORY.md
    IA->>V: lit PRJ_*.md pertinents
    IA->>U: Session prête (contexte chargé)

    loop Micro-avancée (MA)
        U->>IA: Demande unité de travail
        IA->>V: édite fichiers
        IA->>V: git add + commit
        IA->>R: git push
    end

    alt Contexte > 65%
        IA->>V: génère COMPACT_YYYY-MM-DD_HHhMM.md
        IA->>V: push
        IA->>U: propose /compact
    end

    U->>IA: Fin de session
    IA->>V: log SES_NNN_YYYY-MM-DD.md
    IA->>V: update TRK_sessions.md
    IA->>R: push final

05 — Stack d'exécution

Containers Docker isolés, MCP modulaires

Chaque contexte de travail (perso, client A, client B…) tourne dans son propre container : réseau séparé, identité git propre, aucun volume monté. Les intégrations externes passent par des serveurs MCP, ajoutables à chaud.

06 — Git workflow

Commit par micro-avancée, jamais de batch

Une unité atomique de travail = un commit. L'historique raconte exactement comment l'IA a pensé, étape par étape. Un crash en plein milieu ? Le dernier commit est toujours récupérable depuis n'importe quelle machine. 

gitGraph
    commit id: "init vault"
    commit id: "session start"
    branch claude/feature-X
    checkout claude/feature-X
    commit id: "MA: edit PRJ_"
    commit id: "MA: add FB_"
    commit id: "MA: compact"
    checkout main
    merge claude/feature-X
    commit id: "session end"

07 — Principes

7 principes fondateurs

01

Source de vérité unique

Le vault Git. Pas d'info critique ailleurs.

02

Réversibilité totale

Tout est versionné, tout est récupérable.

03

Séparation des couches

Humain ↔ LLM-dense, jamais mélangés.

04

Micro-avancées commitées

Aucun travail perdu sur un crash.

05

Isolation par contexte

Un container par client/projet, identités séparées.

06

Moindre privilège

Chaque outil a l'accès minimum nécessaire.

07

Rigueur > vitesse

Mieux vaut une session lente et exacte qu'une session rapide et approximative. Un agent yes-man qui laisse passer les erreurs est moins utile qu'un interlocuteur qui challenge.

Envie d'implémenter cette architecture ?

Setup complet, onboarding, adaptation à ton stack, formation de ton équipe. Disponible pour des missions courtes (1 semaine) ou longues.
